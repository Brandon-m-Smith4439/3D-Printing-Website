# v1.02 — Full Owner Custom Request tracking

## Editable owner tracking stages
Owner Custom Requests can now start at, and later be changed to, any supported tracking stage:

- New
- Reviewing
- Quote sent
- Quote approved
- Deposit paid
- Queued
- Preparing / slicing
- Printing now
- Finishing / cleanup
- Ready
- On hold
- Completed
- Declined

The selected stage is available during Owner Custom Request creation and remains editable from the Production board after the request is created.

## Tracking vs. financial records
Owner tracking is intentionally separate from quote, payment, queue, invoice, shipping, and fulfillment records. Manually selecting **Deposit paid**, **Printing**, **Ready**, or **Completed** changes the tracking stage only; it does not create a payment, quote, shipping label, or queue record.

When a real owner-created request uses the formal quote/payment/production workflow, those actions automatically keep the owner tracking stage aligned where appropriate.

## Customer visibility
The owner tracking stage is exposed in verified customer profiles and secure guest request pages, and stage changes create the normal customer status update notification when applicable.

## Production board
Owner tracking stages participate in the existing Production filters, including manually tracked production stages such as Preparing, Printing, Finishing, Ready, and On hold.
