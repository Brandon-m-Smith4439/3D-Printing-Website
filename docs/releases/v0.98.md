# v0.98 — Owner Request & Fulfillment Cleanup

## Customer request experience
- Carrier shipping now keeps local/manual payment methods visible but disabled and labeled `(Local pickup only)`.
- New custom requests offer Local pickup or Carrier shipping only. Local delivery is no longer offered for new work.
- Local pickup now uses the designated meetup location at 316 W Jefferson St, Monroe, NC 28112-4714.
- The known legacy pickup default is migrated to the new address without overwriting later owner-customized pickup settings.

## Owner workflow
- The Production tab now uses one real `+ New Custom Request` workflow for in-person, phone, repeat, and direct customers.
- The old Etsy/external manual queue-job creator was removed.
- Owner-created requests link immediately to an existing verified customer account when the email matches.
- Requests created for an email without a verified account remain securely trackable by email and automatically link after that email is verified on a customer account.
- Production status filters with a count of zero are hidden.

## Owner dashboard
- The main Dashboard is now a focused daily overview instead of duplicating Production, Pricing, and Security detail.
- Primary cards are limited to Needs attention, New requests, Active production, and Final balances.
- The four primary cards form one desktop row, with responsive stacking on smaller screens.
- Global search and the needs-attention list remain on the main Dashboard.
- Full request and queue management now appears only under Production.

## Compatibility and safety
- Existing historical local-delivery records remain readable internally; new customer/owner request entry points no longer create local-delivery work.
- Account linking requires a verified matching account for immediate linkage; otherwise normal email verification proves ownership before automatic linking.
- Existing payment, shipping, authentication, upload scanning, and webhook protections are preserved.

## Validation
- Added `tests/v098-owner-request-fulfillment.test.mjs`.
- CI runs the new regression checks together with the existing install, security, pricing, lint, build, integration, and responsive visual checks.
