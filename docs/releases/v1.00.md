# v1.00 — Owner Custom Request Workspace

## Owner Production workflow
- Renames the Production action to **Owner Custom Request**.
- The form no longer expands inline inside the Production board.
- Owner Custom Request opens as a dedicated modal/workspace above the Production page.
- The workspace includes:
  - dedicated header and close control
  - click-outside close
  - Escape-to-close
  - background scroll lock while open
  - clear Cancel action
  - explicit **Submit Owner Custom Request** action
- Existing new-request and historical-completed-request capabilities are preserved inside the dedicated workspace.

## Responsive behavior
- Desktop uses a centered, scrollable modal sized to the viewport.
- At the 720px mobile breakpoint and below, Owner Custom Request becomes a full-height mobile workspace.
- Sticky header/action areas keep Close, Submit, and Cancel accessible while the form scrolls.

## Compatibility
- The request API, account-linking behavior, historical profitability, notifications, fulfillment/payment rules, and Production search are unchanged.
- Only owner-facing presentation and terminology are changed.
