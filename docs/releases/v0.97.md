# v0.97 — Owner quote and dashboard refinement

- One quote builder combines production inputs, cost and margin, quote price, package measurements, and an editable estimated ready date. Removed the redundant target-price button.
- Print duration uses hours; pre-processing and post-processing use minutes. Stored labor hours remain compatible with historical records.
- X2D electricity appears separately from printer wear/overhead. New estimates start at 250 W and $0.1059/kWh, editable per quote; the 550 W PC reference is available as a preset. Power, rate, kWh, and cost are retained in the revision cost snapshot and actual closeout.
- Legacy undecided requests have a customer-confirmation form on the request card; quotes cannot be sent until the missing choices are recorded. Existing submitted choices stay protected.
- Customer assembly, fulfillment, and payment preferences are recorded on public and in-person requests and shown read-only while quoting. Manual payment remains pickup-only.
- Guest email links use the configured public origin behind the hosting proxy; in-person approvals remain available. Quote email results now report send failure explicitly, with a retry action that keeps the quote revision unchanged. Transactional sends use bounded retries and idempotency keys per logical send.
- Dashboard shows estimated and completed revenue, direct costs, and contribution profit. Added email/scanner/bot configuration cards, request status filters, and direct queue position/detail controls. Launch details and manual job creation are collapsible.
- Customer brief/reference and print specification sections start expanded. Added marine-colored scrollbars and margin-slider styling with keyboard focus support.
- Updated the health endpoint to report the application version. Repaired the dependency lockfile so a clean install succeeds.

## Electricity sources and assumptions

Checked 2026-10-02:

- [Bambu X2D FAQ](https://wiki.bambulab.com/en/x2d/manual/x2d-faq): PLA steady printing 250 W and PC 550 W at 25°C, both voltage versions. US peak power is 1100 W; peak power is not the continuous printing estimate.
- [City of Monroe electric fee schedule](https://www.monroenc.org/DocumentCenter/View/2619/City-of-Monroe---Fee-Schedule---Chapter-VI---Electric-PDF): Schedule R charges $0.10590/kWh for the first 300 kWh and $0.09880/kWh thereafter. Rate excludes applicable tax, fixed customer/REPS charges, and any power adjustment. Different utilities or tariffs need an override from the actual electric bill.

Electricity = print hours × average watts / 1000 × price per kWh. Warm-up, room temperature, material settings and AMS drying may change the measured average. Existing snapshots without separate electricity fields retain their historical bundled-rate semantics. Review older machine hourly settings to avoid counting electricity twice.
