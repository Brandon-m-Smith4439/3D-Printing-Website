# V0.90 Pricing & Profitability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an owner-only Bambu Lab material-cost, invoice-import, quote-margin, preset/reuse, actual-cost closeout, and profitability reporting system without exposing internal cost data to customers.

**Architecture:** Store all costing, Bambu purchase, preset, and profitability data in owner-only SQLite-backed collections separate from `StoredQuote`. Seed a verified Bambu US filament catalog, then resolve material cost as weighted actual purchase cost -> verified Bambu MSRP -> explicit manual fallback. Quote revisions receive independent estimate snapshots; Ready/Completed jobs can receive actual/finalized snapshots; Operations Center aggregates contribution profit from those records.

**Tech Stack:** Next.js 16.3.5 App Router, React 19, TypeScript 5.9, Node >=22.5, `node:sqlite`, Zod 4, private Railway volume storage, ClamAV upload scanning, a Node-compatible PDF text parser (`pdfjs-dist`) for text-based Bambu invoices.

**Spec:** `docs/superpowers/specs/2026-09-25-v0.90-pricing-profitability-design.md`

## Global Constraints

- Release version becomes exactly `0.90.0`.
- Manufacturer is Bambu Lab for the seeded filament catalog.
- Initial catalog must cover every Bambu filament family available from the official US filament catalog when implementation begins.
- Current official Bambu US pricing is a reference/MSRP fallback; posted Bambu invoice purchase history is preferred for material cost.
- Invoice uploads and invoice originals remain private and must never be committed to GitHub.
- Bulk/order discounts must affect actual material cost.
- Actual purchase cost is weighted-average landed cost in v0.90; no FIFO spool depletion.
- Internal cost data must not be added to customer-visible `StoredQuote` fields or customer/public APIs.
- Customer deposits and final invoices are collection timing, not additive revenue; quote revenue is counted once.
- Profitability is labeled contribution profit / contribution margin, never accounting net profit.
- Existing 50% deposit / 50% final-balance payment behavior remains unchanged.
- No Stripe live-mode change and no EasyPost live-mode change.
- Existing auth, same-origin, upload malware scanning, backups, and persistent-volume storage protections must remain intact.
- Legacy quotes without costing remain valid and display `Not costed`.
- No automatic customer-price changes: Suggested Price is an owner action only.
- No OCR dependency in v0.90. Text-based Bambu invoice PDFs are supported; non-text PDFs are marked review-required and may be entered manually.
- Actual private invoice fixtures supplied by the owner are used only to tune parsing and validate behavior; committed tests use sanitized synthetic fixtures.

## Review Focus

1. **Invoice contains filament plus non-filament merchandise:** shared discount/shipping/tax allocation must not assign every shared charge to filament; Task 4 includes a mixed-order allocation test.
2. **Bambu changes package size or offers a 0.5 kg product:** per-gram cost must use catalog/purchase net grams rather than assuming 1000 g; Tasks 1 and 3 test 500 g and 1000 g products.
3. **Customer API serializes a quote after v0.90:** no costing, invoice, purchase-lot, margin, or profitability fields may appear; Task 9 adds an explicit response leak test.
4. **Quote revision changes after an estimate exists:** revision 1 cost remains immutable/history-safe and revision 2 gets a new estimate ID; Task 5 tests revision isolation.
5. **Suggested-price solver sees an impossible target + fee rate >= 100%:** reject/flag the configuration instead of dividing by zero or returning nonsense; Tasks 2 and 5 test invalid denominators.

Create `lib/pricing-math.ts`:

```ts
import type { PricingSettings } from "./pricing-types.ts";

export function costPerGramMicros(totalCostCents: number, netWeightGrams: number) {
  if (!Number.isFinite(totalCostCents) || totalCostCents < 0) throw new Error("Cost must be non-negative.");
  if (!Number.isFinite(netWeightGrams) || netWeightGrams <= 0) throw new Error("Net weight must be greater than zero.");
  return Math.round((totalCostCents * 1_000_000) / netWeightGrams);
}

export function materialCostCents(grams: number, costPerGramValueMicros: number) {
  if (grams <= 0 || costPerGramValueMicros <= 0) return 0;
  return Math.round((grams * costPerGramValueMicros) / 1_000_000);
}

export function paymentFeeCents(
  revenueCents: number,
  settings: Pick<PricingSettings, "defaultPaymentFeePercentBasisPoints" | "defaultPaymentFeeFixedCents">,
) {
  if (revenueCents <= 0) return 0;
  return Math.round(revenueCents * settings.defaultPaymentFeePercentBasisPoints / 10_000)
    + Math.max(0, settings.defaultPaymentFeeFixedCents);
}

export function suggestedRevenueCents(
  nonPaymentDirectCostCents: number,
  settings: Pick<PricingSettings, "targetContributionMarginBasisPoints" | "defaultPaymentFeePercentBasisPoints" | "defaultPaymentFeeFixedCents">,
) {
  const target = settings.targetContributionMarginBasisPoints / 10_000;
  const feeRate = settings.defaultPaymentFeePercentBasisPoints / 10_000;
  const denominator = 1 - target - feeRate;
  if (denominator <= 0) throw new Error("Target margin and payment fee assumptions leave no valid selling price.");
  return Math.ceil((Math.max(0, nonPaymentDirectCostCents) + Math.max(0, settings.defaultPaymentFeeFixedCents)) / denominator);
}

export function contributionMetrics(
  revenueCents: number,
  nonPaymentDirectCostCents: number,
  settings: Pick<PricingSettings, "targetContributionMarginBasisPoints" | "defaultPaymentFeePercentBasisPoints" | "defaultPaymentFeeFixedCents">,
) {
  const fee = paymentFeeCents(revenueCents, settings);
  const directCostCents = Math.max(0, nonPaymentDirectCostCents) + fee;
  const contributionProfitCents = revenueCents - directCostCents;
  const contributionMarginBasisPoints = revenueCents > 0
    ? Math.round(contributionProfitCents / revenueCents * 10_000)
    : 0;
  return { paymentFeeCents: fee, directCostCents, contributionProfitCents, contributionMarginBasisPoints };
}
```

import { spawn } from "node:child_process";

export async function malwareScanPrivateFile(filePath: string) {
  const scanner = (process.env.CUSTOMER_UPLOAD_SCANNER || "").trim().toLowerCase();
  if (scanner !== "clamav") {
    if (process.env.NODE_ENV === "production") throw new Error("File scanning is temporarily unavailable.");
    return "development-unscanned" as const;
  }
  const executable = (process.env.CLAMSCAN_PATH || "clamscan").trim();
  return new Promise<"clean">((resolve, reject) => {
    const child = spawn(executable, ["--no-summary", filePath], { stdio: ["ignore", "pipe", "pipe"], shell: false });
    let stderr = "";
    const timer = setTimeout(() => { child.kill(); reject(new Error("Malware scan timed out.")); }, 30_000);
    child.stderr.on("data", (data) => { stderr += String(data).slice(0, 2000); });
    child.on("error", () => { clearTimeout(timer); reject(new Error("Malware scanner could not start.")); });
    child.on("close", (code) => {
      clearTimeout(timer);
      if (code === 0) resolve("clean");
      else if (code === 1) reject(new Error("The uploaded file was rejected by malware scanning."));
      else reject(new Error(stderr || "Malware scanner failed."));
    });
  });
}

export async function extractPdfText(bytes: Uint8Array) {
  const pdfjs = await import("pdfjs-dist/legacy/build/pdf.mjs");
  const doc = await pdfjs.getDocument({ data: bytes, useWorkerFetch: false, isEvalSupported: false }).promise;
  const pages: string[] = [];
  for (let pageNumber = 1; pageNumber <= doc.numPages; pageNumber += 1) {
    const page = await doc.getPage(pageNumber);
    const text = await page.getTextContent();
    pages.push(text.items.map((item) => "str" in item ? item.str : "").join(" "));
  }
  return pages.join("\n");
}
