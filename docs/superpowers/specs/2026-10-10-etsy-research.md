# Etsy connection and research scope

Build an owner-only Etsy adapter, disabled until configured. Official OAuth authorization-code PKCE with random, single-use, ten-minute state bound to the current owner session. Store verifier and access/refresh tokens encrypted with an environment-only AES-256 key in a separate persistent sidecar. Request only shops_r, listings_r, transactions_r. Verify the authorized user's shop matches MeshHarbor3D (configurable expected name), rather than accepting a browser sign-in as authorization.

Owner-triggered research reads a bounded official marketplace search and records its source and observation time. Results are search observations and favorite counts, not competitor item sales or bestseller rankings. Owner-shop sales read paid/non-canceled receipts over a defined window, bounded pagination, aggregate transaction quantities and item prices by currency, strip customer data, and explicitly report truncation and refunds/fees limitations. Never pass returned text to an agent automatically.

Export a manual Etsy listing package only from a current physically tested release with a separately owner-approved listing draft. No listing creation/publication, message, charge, payment or refund endpoint exists. Credentials, app approval, precise HTTPS callback registration and owner OAuth grant remain configuration blockers. All implementation verification uses isolated fixtures; no live calls or deployment.

## Owner-directed publication extension

The parent agent subsequently authorized implementing an optional smallest publication executor. This supersedes the no-listing-endpoint implementation constraint above while preserving no external writes during development. `ETSY_WRITES_ENABLED` defaults off. Read grants stay default; explicit separate OAuth adds listings_w and binds that mode to state. Only current tested original releases with exact-version approved drafts may create an immutable preview. One separately allocated unit, original bounded JPEG/PNG, exact tested STL for download, USD shop and correct owner-entered physical profile IDs are required. A separate exact-preview approval acknowledges Etsy fees before create/upload/activate. Writes commit a durable claim before I/O, never retry unknown outcomes and never run in background workers. Platform charges cannot be hard-capped by this application and are explicitly separate from the AI API ledger. Live setup and verification remain external blockers.
