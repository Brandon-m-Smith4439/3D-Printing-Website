# Reviewed product commerce

Independent commerce SQLite stores immutable release snapshots, copied STL bytes and owner approvals. Publication and Checkout default off. Every preparation/approval requires the latest source revision's passing physical test and originality acknowledgement. Catalog visibility checks the source release remains current. Physical inventory is atomically reserved across processes. Unknown payment outcomes retain reservations; only matching signed expiration/failure releases them. Paid fulfillment is idempotent and validates session, mode, prices, fingerprint, shipping, tax and currency. Hashed customer bearer tokens protect status and digital files; no email is sent automatically.

Public responsive catalogs and cart use server pricing. Explicit shipping country/rate and tax review configuration are required; Stripe mode safety is reused. Separate signed webhook avoids altering existing quote payments. Owner catalog/order UI supports review, withdrawal, inventory adjustment and physical fulfillment. No seed catalog, external execution, live payment or deployment during implementation.
