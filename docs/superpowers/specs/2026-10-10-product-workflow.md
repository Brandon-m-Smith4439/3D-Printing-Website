# Product project workflow

The owner authorized workflow decisions and incremental implementation on the existing draft branch. Extend the existing private Next.js owner center; preserve the production checkout and request workflows. Implement the first independently useful increment now; do not deploy or publish.

Business workspaces: Mesh Harbor physical prints/STLs and independent digital products. A bounded coordinator delegates a planning, research, design/refinement, or listing job based on project state. Jobs retain existing monthly business budgets and per-call spending approval. Leader planning output is advisory text; it cannot grant permissions or execute tools. Project briefs and explicitly entered research evidence are the only business context sent to the provider. No autonomous browsing or verified marketplace sales ranking is claimed.

Projects contain owner ideas, sourced observations, immutable STL revisions and hashes, revision-specific physical test outcomes, and a private release package. New revisions and failed tests invalidate release preparation. STL analysis is structural only, with finite geometry, nondegenerate triangles, closed/oriented edges and bounds; slicer review and actual print testing remain necessary. A free parametric tray generator creates an original starting STL, without executing model-generated code.

Responsive workspace navigation, role task cards, polling activity, owner actions, project details, refinement feedback and catalog/cart previews must represent stored state. Catalog previews are owner-only; no public product listing, payment or download fulfillment is enabled. A release package requires current revision passing a physical test and explicit originality/license acknowledgement. Etsy credentials, access, fees, exact stock synchronization, Stripe catalog checkout and secure digital delivery are subsequent integrations, documented honestly.

Etsy shop rebranding is authorized but blocked by browser sign-in/device check. Prepare branding content while awaiting access; do not bypass checks or ask for passwords. Railway configuration remains untouched until deployment approval.
